<p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 14pt;"><strong>Input: </strong>n = 36
<strong>Output: </strong>4
<strong>Explanation: </strong>36 / 4 = 9, which is odd. No smaller positive divisor makes the quotient odd.</span></pre>

<strong>Output: </strong>1
<strong>Explanation: </strong>5 is already odd, so no division is required.</span></pre>
