<h2><a href="https://www.geeksforgeeks.org/problems/maximum-number-of-22-squares/1">Squares in Triangle</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given the <strong>base </strong>(in units) of a right-angled isoceles traingle, find the <strong>maximum</strong> number of 2X2 squares that can fit in the triangle with given base.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input:</strong> base = 8</span>
<span style="font-size: 18px;"><strong>Output:</strong> 6</span>
<strong><span style="font-size: 18px;">Explanation:</span></strong>
<span style="font-size: 18px;">The bottom row can accommodate 3 squares, the next row 2 squares, and the top row 1 square. Hence, the maximum number of 2 × 2 squares that can fit inside the triangle is: 3 + 2 + 1 = 6.
<img style="height: 337px; width: 390px;" src="https://media.geeksforgeeks.org/wp-content/uploads/squares-in-triangle1.png" alt="squares-in-triangle"></span>
</pre>
<pre><span style="font-size: 18px;"><strong>Input : </strong>base <strong>= </strong>7
<strong>Output : </strong>3
<strong>Explanation : </strong>In the base we can keep 2 squares and above the two squares we can only keep 1 square. So the total number of squares are equal to 3.</span>
</pre>
